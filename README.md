# Eagle's Wings Foundation Tanzania

Frontend for Eagle's Wings Foundation Tanzania, built with Tailwind CSS.

## Local preview

1. Clone or pull the repository.
2. Open the project folder in VS Code.
3. Start **Live Server** from `index.html` (recommended), or run a simple local server such as `python -m http.server 8080`.
4. Open `http://localhost:8080` when using the Python server.

## Current frontend

- Tailwind CSS via CDN for rapid design iteration
- Responsive single-page hash routing
- Premium navy/orange NGO design system
- Home, About, Programs, Impact, Get Involved, Events, News, Gallery, Reports, Partners, Careers, FAQ, Contact, Privacy, Resources and Donate views
- Mobile navigation and WhatsApp action
- Donation and forms are frontend prototypes until backend/payment integrations are connected
- No mountain imagery
